# 业务实体知识

cgroup_sched_plugin 模块核心业务实体的完整知识定义，涵盖静态概念、动态运行、规则约束与代码映射。

## 调度策略组（SchedPolicy）

### 实体概念

| 子维度   | 内容                                                                                     |
| ----- | -------------------------------------------------------------------------------------- |
| 实体名称  | 调度策略组 / SchedPolicy                                                                    |
| 实体定义  | 对进程/线程归属的 cgroup 子组的逻辑抽象，决定进程在 CPU 调度上的优先级档位                                          |
| 核心特征  | 取值固定 5 类：SP_DEFAULT=0、SP_BACKGROUND=1、SP_FOREGROUND=2、SP_SYSTEM_BACKGROUND=3、SP_TOP_APP=4；上限 SP_UPPER_LIMIT=0xff |

### 上下文与场景

| 子维度  | 内容                                                                      |
| ---- | ----------------------------------------------------------------------- |
| 交互流程 | 事件处理层修改进程的 `SchedPolicy` → 执行层 `ComputeProcessGroup` 计算最终组别 → `ApplyProcessGroup` 下发到内核 cgroup |

### 知识关联

| 子维度   | 内容                                                                  |
| ----- | ------------------------------------------------------------------- |
| 下游影响  | `ProcessRecord::curSchedGroup_`（进程当前组别） |
| 平级关联  | `AdjustSource`（触发重算的语义来源）                                          |

### 代码与符号

| 子维度 | 内容                                                                                  |
| --- | ----------------------------------------------------------------------------------- |
| 核心类 | `SchedPolicy`（`framework/process_group/include/sched_policy.h`）                     |

## 进程记录（ProcessRecord）

### 实体概念

| 子维度   | 内容                                                                                                       |
| ----- | -------------------------------------------------------------------------------------------------------- |
| 实体名称  | 进程记录 / ProcessRecord                                                                                    |
| 实体定义  | 描述一个进程的运行态快照，是策略计算的唯一数据源                                                                               |
| 核心特征  | 持有 uid、pid、进程名、进程类型、进程状态、能力列表、窗口列表、焦点、可见性、瞬态任务、连续任务、音频播放/采集、相机、蓝牙、Wi-Fi、MMI、运行锁、屏幕录制、视频、Nap、键线程、序列号、宿主 pid 等字段 |
| 类型/分类 | `ProcRecordType`：NORMAL=0、EXTENSION=1、RENDER=2、GPU=3、CHILD=4                                            |

### 上下文与场景

| 子维度  | 内容                                                                                            |
| ---- | --------------------------------------------------------------------------------------------- |
| 交互流程 | 进程创建事件触发创建 → 事件处理层各 `Handle*` 更新字段 → 进程死亡事件移除 → 执行层 `ComputeProcessGroup` 读取字段计算 `SchedPolicy` |
| 状态流转 | `lastSchedGroup_`/`curSchedGroup_`/`setSchedGroup_`/`specialSchedGroup_` 记录调度组别变迁             |

### 规格与约束

| 子维度 | 内容                                                                                            |
| --- | --------------------------------------------------------------------------------------------- |
| 业务规则 | 应用名与进程名仅在为空时设置，已设置后不覆盖；附属进程（渲染/GPU/子进程）的组别跟随宿主进程；`curSchedGroup_` 仅在下发成功后更新 |
| 并发约束 | 状态变更必须在 `CgroupEventHandlerQueue` 队列任务内执行                                                    |

### 知识关联

| 子维度   | 内容                                                |
| ----- | ------------------------------------------------- |
| 上层依赖  | `Application`（uid 维度的进程集合）                        |
| 下游影响  | `SchedPolicy`（策略计算输入）       |
| 平级关联  | `AbilityInfo`、`WindowInfo`（能力与窗口状态影响策略计算）         |

### 代码与符号

| 子维度 | 内容                                                                          |
| --- | --------------------------------------------------------------------------- |
| 核心类 | `ProcessRecord`、`Application`、`AbilityInfo`、`WindowInfo`（`framework/sched_controller/include/supervisor.h`） |
